
# Questlog 🎮

A personal Super Mario game backlog where you can keep track of the games you want to play, are currently playing, have completed, or decided to drop.

Questlog makes it easy to organize your gaming library, rate your games, add personal notes, and keep track of your gaming journey.

## Features

- View all games in your collection
- Add new games
- Edit existing games
- Delete games
- View individual game details
- Filter games by status
- Rate games and add personal notes
- Loading indicators and error handling
- Responsive design

## Tech Stack

- React
- TypeScript
- Vite
- SCSS
- React Router
- REST API

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone [(https://github.com/elenaholmberg/games/)]
   ```

2. Navigate to the project folder:

   ```bash
   vite-project
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.
