Questlog 🎮

A personal game backlog where you can keep track of the games you want to play, are currently playing, have completed, or decided to drop.

Questlog makes it easy to organize your gaming library, rate your games, add personal notes, and keep track of your gaming journey.

Features

View all games in your collection

Add new games

Edit existing games

Delete games

View individual game details

Filter games by status

Rate games and add personal notes

Loading indicators and error handling

Responsive design

Tech Stack

React

TypeScript

Vite

SCSS

React Router

REST API

Getting Started

Prerequisites

Make sure you have Node.js and npm installed.

Installation

Clone the repository:

git clone YOUR_REPOSITORY_URL

Navigate to the project folder:

cd questlog

Install dependencies:

npm install

Start the development server:

npm run dev

Open the local URL provided by Vite in your browser.

API

Questlog uses a REST API to store and manage game data.

API handle: elena

API endpoint:
https://questlog-api.vercel.app/api/elena/games
